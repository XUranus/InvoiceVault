# 常量与状态码

InvoiceVault 在 `src-tauri/src/app_core/constants.rs` 中集中定义了所有应用级常量，便于统一调优和维护。

| 常量 | 值 | 说明 |
|------|-----|------|
| `DIR_LOGS` | `"logs"` | 日志文件目录 |
| `DIR_MODELS` | `"models"` | Embedding 模型存储目录 |

## 状态常量模块

状态常量定义在 `constants::status` 子模块中，用于替代代码中的字符串字面量：

### 导入任务状态

| 常量 | 值 | 说明 |
|------|-----|------|
| `IMPORTED` | `"imported"` | 已导入 |
| `FAILED` | `"failed"` | 导入失败 |
| `RECOGNIZING` | `"recognizing"` | 正在识别中 |
| `COMPLETED` | `"completed"` | 已完成 |
| `PENDING` | `"pending"` | 等待处理 |
| `CONFIRMED` | `"confirmed"` | 已确认 |
| `ARCHIVED` | `"archived"` | 已归档 |

### 去重状态

| 常量 | 值 | 说明 |
|------|-----|------|
| `UNIQUE` | `"unique"` | 唯一发票 |
| `EXACT_DUPLICATE` | `"exact_duplicate"` | 精确重复 |
| `PROBABLE_DUPLICATE` | `"probable_duplicate"` | 可能重复 |
| `POSSIBLE_DUPLICATE` | `"possible_duplicate"` | 疑似重复 |
| `NOT_DUPLICATE` | `"not_duplicate"` | 非重复 |

### 使用方式

```rust
use crate::app_core::constants::status;

// 推荐：使用常量
state.set_import_job_status(raw_file_id, status::RECOGNIZING, None)?;

// 不推荐：使用字符串字面量
state.set_import_job_status(raw_file_id, "recognizing", None)?;
```

## 如何添加新常量

当需要添加新的应用级常量时，请遵循以下步骤：

1. 打开 `src-tauri/src/app_core/constants.rs`
2. 在合适的分类区域添加常量定义
3. 添加文档注释说明常量用途
4. 在需要使用的模块中引入常量

```rust
// 示例：在 constants.rs 中添加新常量

// ---------------------------------------------------------------------------
// 新功能参数
// ---------------------------------------------------------------------------

/// 新功能的默认超时时间（秒）。
pub const NEW_FEATURE_TIMEOUT_SECS: u64 = 60;

/// 新功能的最大重试次数。
pub const NEW_FEATURE_MAX_RETRIES: u32 = 5;
```

### 注意事项

- 常量值应有明确的单位后缀（如 `_SECS`、`_MS`、`_BYTES`）
- 每个常量都需要文档注释（`///`）
- 将相关常量放在同一分类区域中
- 状态常量应放在 `status` 子模块中
- 避免在代码中直接使用字符串字面量表示状态
